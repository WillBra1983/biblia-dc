Política de Privacidade

Última atualização: 2025

Este documento descreve como o aplicativo [NOME DO SEU APP] trata os dados do usuário. O aplicativo foi desenvolvido para operar totalmente offline e não coleta, armazena, processa ou compartilha qualquer tipo de informação pessoal.

1. Coleta de Informações

O aplicativo não coleta quaisquer dados pessoais, sensíveis ou estatísticos. Nenhum nome, e-mail, telefone, localização, identificador ou qualquer outro dado é solicitado ou registrado.

2. Uso de Dados

Como o aplicativo não coleta dados, não há uso, processamento ou análise de informações do usuário.

3. Armazenamento de Dados

Nenhuma informação pessoal é armazenada no dispositivo ou enviada para servidores externos. Todo o funcionamento do app ocorre localmente.

4. Compartilhamento de Informações

Não há compartilhamento de informações com terceiros, pois o aplicativo não coleta nenhum dado.

5. Permissões do Dispositivo

O aplicativo não solicita permissões especiais como câmera, localização, microfone, arquivos, contatos ou acesso à internet. Se alguma permissão mínima for solicitada pelo sistema operacional, ela não envolve coleta de dados.

6. Publicidade e Analytics

O aplicativo não utiliza anúncios, ferramentas de análise, rastreamento ou envio de dados para qualquer servidor.

7. Segurança

Como nenhuma informação pessoal é coletada, o risco de exposição, vazamento ou uso indevido de dados é inexistente.

8. Alterações nesta Política

Alterações futuras nesta política serão publicadas através desta mesma página.
