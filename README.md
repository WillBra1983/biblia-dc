# Bíblia DC

App **Capacitor 6** (React + Vite): Android, iOS e PWA.

## Pasta principal

Trabalhe sempre em **`C:\salvation`**.

| Plataforma | Comandos |
|------------|----------|
| Desenvolvimento web | `npm run dev` |
| Android (APK/AAB) | `npm run android:sync` → `npm run android:build` |
| iOS (sync web) | `npm run ios:sync` |
| iOS (Mac/Xcode) | `npm run ios:open` |
