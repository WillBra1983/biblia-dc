Use este arquivo como base para a secao de atribuicoes no app e no site.

## Como usar

Para cada fonte externa integrada ao produto, preencher:

- Nome da obra/dataset
- Origem (URL)
- Versao/commit/tag usado na importacao
- Licenca
- Texto de atribuicao exigido
- Arquivo local que contem os dados no app
